# ระบบตรวจประเมินภายใน (Internal Audit)

เว็บแอปสำหรับทีมตรวจประเมินภายใน ใช้เก็บแผนตรวจ PDF, ดูโครงสร้างสาขา, กรอกแบบฟอร์มพร้อม checklist และติดตามสถานะเอกสารจนปิดงาน

ฐานข้อมูลใช้ **Supabase (PostgreSQL)** ผ่าน Prisma

## เริ่มต้นใช้งาน

1. สร้างโปรเจกต์ที่ [Supabase](https://supabase.com/dashboard)
2. ไปที่ **Project Settings → Database → Connection string**
   - `DATABASE_URL` ใช้โหมด **Transaction pooler** (พอร์ต `6543`) แล้วต่อท้าย `?pgbouncer=true`
   - `DIRECT_URL` ใช้โหมด **Session** (พอร์ต `5432`) สำหรับ `prisma db push` / migrate
3. คัดลอก `.env.example` เป็น `.env` แล้วใส่รหัสผ่านและ Project ref

```bash
npm install
npx prisma db push
npx prisma db seed
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

ตารางจะไปอยู่ใน schema `public` ของ Supabase เช่น `users`, `departments`, `audit_documents`, `audit_plans`, `checklist_items`

### บัญชีทดลอง

| สิทธิ์ | ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- | --- |
| Admin | `admin` | `admin123` |
| User | `user` | `user123` |

## สิทธิ์การใช้งาน

- **ทุกคน** ต้องล็อกอินก่อนใช้งาน
- **User** แนบ/ดูแผน PDF, เปิดแบบฟอร์มจากแผนก, สร้างเอกสาร และแก้ได้เฉพาะตอนยังเป็นร่าง
- **Admin** ทำได้ทั้งหมด รวมถึงแก้ชื่อ/เปลี่ยน/ลบไฟล์แผน, เพิ่ม-ลบแผนก, แก้เอกสารที่ส่งแล้ว และเปลี่ยนสถานะ

## โมดูลหลัก

1. **หน้าหลัก** — สรุปจำนวนเอกสาร, งานที่ยังไม่ปิด, PDF แผนตรวจ และจำนวนแผนก
2. **แผนการตรวจประเมิน** — คลังไฟล์ PDF
3. **ผังองค์กร & โครงสร้างสาขา** — HO / BP / LB กด “ตรวจแผนก” เพื่อเปิดแบบฟอร์ม (checkbox เป็นเพียงการแสดงโครงสร้าง)
4. **แบบฟอร์มตรวจประเมิน** — หัวเอกสาร, checklist, ลงนาม บันทึกร่างหรือส่งเอกสาร
5. **รายการเอกสารทั้งหมด** — ค้นหา กรองสถานะ เรียงคอลัมน์ ดูรายละเอียด พิมพ์ แก้/ลบ (Admin)

สถานะที่ใช้ติดตาม: ร่าง, รอรับทราบ, รออนุมัติการแก้ไข, แนบเรื่องรอดำเนินการ, ถอนแบบ, รอ MR อนุมัติ, ปิดเอกสารสมบูรณ์
