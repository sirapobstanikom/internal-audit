# ระบบตรวจประเมินภายใน (Internal Audit)

เว็บแอปสำหรับทีมตรวจประเมินภายใน ใช้เก็บแผนตรวจ PDF, ดูโครงสร้างสาขา, กรอกแบบฟอร์มพร้อม checklist และติดตามสถานะเอกสารจนปิดงาน

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

### บัญชีทดลอง

| สิทธิ์ | ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- | --- |
| Admin | `admin` | `admin123` |
| Leader Audit | `leader` | `leader123` |
| User | `user` | `user123` |

> ถ้ายังไม่มีบัญชี `leader` ในฐานข้อมูล ให้รัน SQL ใน `supabase/seed-leader-audit.sql`

## สิทธิ์การใช้งาน

- **ทุกคน** ต้องล็อกอินก่อนใช้งาน
- **User** แนบ/ดูแผน PDF, เปิดแบบฟอร์มจากแผนก, สร้างเอกสาร และแก้ได้เฉพาะตอนยังเป็นร่าง
- **Leader Audit** เหมือน User และมีแท็บ **รับทราบ/เอกสาร** เพื่ออนุมัติผ่าน / ไม่ผ่าน / ตีกลับเอกสารที่ส่งแล้ว
- **Admin** จัดการโครงสร้างองค์กร แผน PDF และเอกสารทั่วไป (ไม่อนุมัติเอกสารตรวจ)

## โมดูลหลัก

1. **หน้าหลัก** — สรุปจำนวนเอกสาร, งานที่ยังไม่ปิด, PDF แผนตรวจ และจำนวนแผนก
2. **แผนการตรวจประเมิน** — คลังไฟล์ PDF
3. **ผังองค์กร & โครงสร้างสาขา** — HO / BP / LB กด “ตรวจแผนก” เพื่อเปิดแบบฟอร์ม (checkbox เป็นเพียงการแสดงโครงสร้าง)
4. **แบบฟอร์มตรวจประเมิน** — หัวเอกสาร, checklist, ลงนาม บันทึกร่างหรือส่งเอกสาร
5. **รับทราบ/เอกสาร** — สำหรับ Leader Audit อนุมัติผ่าน / ไม่ผ่าน / ตีกลับ
6. **รายการเอกสารทั้งหมด** — ค้นหา กรองสถานะ เรียงคอลัมน์ ดูรายละเอียด พิมพ์ แก้/ลบ (Admin)

สถานะที่ใช้ติดตาม: ร่าง, รอรับทราบ, รออนุมัติการแก้ไข, แนบเรื่องรอดำเนินการ, ไม่ผ่าน, รอ Leader อนุมัติ, ปิดเอกสารสมบูรณ์

### ลำดับงานหลังส่งเอกสาร

1. User ส่งเอกสาร → สถานะ **รอรับทราบ**
2. Leader Audit ที่เมนู **รับทราบ/เอกสาร** เลือก **อนุมัติผ่าน** / **ไม่ผ่าน** / **ตีกลับ**
